# Findings Log

Этот файл предназначен для накопления сравнительных наблюдений.

Для каждой записи желательно фиксировать:
- дату;
- benchmark;
- сравниваемые версии;
- краткое наблюдение;
- структурную причину;
- рекомендацию:
  - перенести в core;
  - оставить runtime-specific;
  - проверить в следующем прогоне.
