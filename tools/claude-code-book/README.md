- Если вы проектируете агента для долгих многочасовых прогонов и он со временем теряет когерентность, останавливается или требует все больше ручной сборки контекста, откройте [harness-design-long-running-apps-RU.md](/Users/alexeykrolmini/Code/essays/tools/claude-code-book/harness-design-long-running-apps-RU.md).
- Если вы хотите понять, как устроить planner/generator/evaluator harness для сложных приложений, фронтенд-дизайна и длинной автономной разработки, этот же файл — основной reference.
- Если вы решаете, стоит ли делать отдельный раздел про harness engineering в основном курсе, эта папка — место для оценки и будущей интеграции материала.
