# Claude Code Workspace

Именно здесь `Claude Code` должен реализовывать целевую инфраструктуру.

Ожидаемый результат:

```text
runtimes/claudecode/workspace/agent_org/
```

Также здесь должны появиться Claude Code-specific runtime-файлы:
- `CLAUDE.md`
- `.claude/settings.json`
- `.claude/agents/`
- `.claude/skills/`
- `.claude/rules/`
- `.claude/hooks/`
