# Quality Gates

Gate 1: Product
- Product brief exists and states success criteria.

Gate 2: Engineering
- Engineering spec exists and maps to the product brief.
- Task graph exists and references the engineering spec.

Gate 3: Execution
- Work order exists and status board updated.
- Handoff log contains required transitions.

Gate 4: Evaluation
- Benchmark result recorded for GT-001.
- Process audit recorded.

Gate 5: Evolution
- Improvement backlog has at least one entry.
