# Escalation Policy

Escalate immediately if any of the following occur:
- A request requires modifying `core/` or `runtimes/codex/`.
- The GT-001 required artifacts cannot be created.
- The sandbox write scope must be violated to proceed.

Escalation steps:
1. Record the issue in `knowledge/decision_log.md`.
2. Add a change proposal in `evolution/change_proposals.md`.
3. Pause execution until guidance is provided.
