# Scope and Boundaries

In scope:
- Build the minimal agent organization structure required by GT-001.
- Produce product, engineering, execution, evaluation, evolution, and state artifacts.
- Configure Claude Code runtime files that support governance and bootstrap.

Out of scope:
- Editing core source-of-truth documents in `core/`.
- Modifying `runtimes/codex/` or `comparison/`.
- Implementing production code or real services.

Hard boundaries:
- Write scope is limited to `runtimes/claudecode/workspace/`, `runtimes/claudecode/runs/`, `runtimes/claudecode/evaluation/`.
- Structure changes require a logged change proposal.
