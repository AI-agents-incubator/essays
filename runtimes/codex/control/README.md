# Codex Runtime Control Layer

> Версия файла: `v1.0`
> Дата версии: `2026-03-17`
> Тип документа: `runtime-local control plane`

Этот каталог является локальным inbox/outbox для `Codex`.

Здесь лежат только те control-артефакты, которые runtime должен:

- читать без выхода за пределы своей sandbox;
- обновлять без нарушения write scope;
- использовать как единственный оперативный канал связи с наблюдателем.

`execution_plane` синхронизирует этот каталог с центральным `/control_plane/`.
