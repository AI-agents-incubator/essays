# Engineering Spec Template

Purpose: translate a product brief into executable tasks and constraints.

Owner: `engineering-manager`

Required fields:
- Work item ID
- Scope summary
- Non-goals
- Required artifacts
- State layer requirements
- Task breakdown
- Acceptance criteria
- Handoffs

Update rules:
- Created by `engineering-manager`.
- Reviewed by `review-and-integration-agent`.
