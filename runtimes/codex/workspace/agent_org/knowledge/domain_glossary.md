# Domain Glossary

Purpose: define key terms used by the organization.

Owner: `learning-agent`

Terms:
- Artifact layer: markdown files that explain and govern the organization.
- State layer: operational state stored in SQLite for long-lived memory.
- Work item: a unit of demand tracked end-to-end.
- Handoff: a role-to-role transfer recorded in logs.
- Benchmark: a canonical task used to evaluate runtime performance.

Update rules:
- Append-only.
- Changes must be noted in `knowledge/decision_log.md`.
