# First Run Protocol

Purpose: checklist for the first GT-001 bootstrap run.

Owner: `org-bootstrap`

Checklist:
- Confirm `agent_org/` structure exists.
- Populate all required templates with minimal operational content.
- Create product brief `PB-001_GT-001.md`.
- Create engineering spec `ES-001_GT-001.md`.
- Create work order `WO-001_GT-001.md`.
- Record handoffs and integration log.
- Populate evaluation and learning traces.
- Ensure SQLite schema and state registry exist.

Exit criteria:
- All GT-001 expected artifacts exist.
- Run summary and evaluation trace are recorded.
