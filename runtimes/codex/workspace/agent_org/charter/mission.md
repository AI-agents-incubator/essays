# Mission

Purpose: define why this agent organization exists and what success means.

Owner: `business-sponsor-interface`

Mission statement:
- Turn external product demands into a reproducible, auditable delivery cycle.
- Keep work traceable across product, engineering, execution, evaluation, and learning.
- Preserve long-term operational context through an explicit state layer.

Success criteria:
- Each external signal results in a clearly tracked work item.
- The cycle completes with benchmark and learning traces.
- The organization is ready for the next run without manual reconstruction.

Update rules:
- Only `business-sponsor-interface` can change the mission.
- Changes must be logged in `knowledge/decision_log.md`.
- Any change requires a matching entry in `evolution/approved_changes.md`.
