# Triage Rules

Purpose: define how incoming signals become work items.

Owner: `product-lead`

Rules:
- Every signal must be mapped to a `WI-*` work item.
- Assign a priority and required roles.
- Create a product brief before engineering work begins.

Default prioritization:
- Benchmark/bootstrap tasks are high priority.
- Structural changes are medium priority.
- Nice-to-have improvements are low priority.

Update rules:
- Proposed by `product-lead`, approved by `engineering-manager`.
