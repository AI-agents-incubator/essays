# Product Brief Template

Purpose: capture intent, scope, and success criteria for a work item.

Owner: `product-lead`

Required fields:
- Work item ID
- Goal and problem statement
- Out of scope
- Success criteria
- Dependencies
- Risks and assumptions
- Required handoffs

Update rules:
- Created by `product-lead`.
- Reviewed by `engineering-manager`.
- Changes logged in `knowledge/decision_log.md`.
