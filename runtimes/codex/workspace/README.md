# Codex Workspace

Именно здесь `Codex` должен реализовывать целевую инфраструктуру.

Ожидаемый результат:

```text
runtimes/codex/workspace/agent_org/
```

Также здесь должны появиться Codex-specific runtime-файлы:
- `AGENTS.md`
- `.codex/config.toml`
- `.codex/agents/`
- `.agents/skills/`

Именно файл `AGENTS.md` должен быть entrypoint-файлом для запуска `Codex` в этой песочнице.
