# Comparison Criteria

## Общий принцип

Сравниваются не литературные качества текста, а **качество организационной инфраструктуры как системы**.

## Критерии

1. Полнота структуры
2. Ясность bootstrap-логики
3. Качество role separation
4. Качество artifact architecture
5. Качество benchmark-контура
6. Качество learning-контура
7. Качество state layer и долгоживущей памяти
8. Удобство независимой валидации
9. Готовность к следующему автономному запуску

## Формат оценки

Для каждого критерия нужно фиксировать:
- сильные стороны;
- слабые стороны;
- структурные риски;
- что можно перенести в общее ядро;
- что остаётся runtime-specific.
