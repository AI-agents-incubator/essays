# Expected Result Template

## Result Identity

- идентификатор benchmark-задачи;
- версия expected result;

## Итоговые артефакты

Перечислите артефакты, которые обязательно должны существовать после успешного прогона.

## Ключевые свойства результата

- полнота;
- связность;
- отсутствие недопустимых побочных эффектов;
- пригодность к следующему этапу.

## Expected Process Signature

Опишите минимальную сигнатуру правильного процесса:
- обязательные роли;
- обязательные handoff;
- обязательные контрольные точки;
- обязательные evaluation-артефакты.

## Failure Signature

Опишите признаки, которые однозначно означают провал.
