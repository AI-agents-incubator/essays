# State Layer

Этот каталог описывает **слой состояния** для агентной организации.

Это не замена артефактной архитектуры, а её структурное дополнение.

## Главный принцип

Долгоживущая агентная организация не может опираться только на markdown-файлы.

Ей нужны два слоя одновременно:

1. **Артефактный слой**
   Читаемые человеком документы, правила, логи, шаблоны, policy и explainability.

2. **State layer**
   Структурированное хранилище состояний, переменных, статусов, очередей, событий, run trace и operational metadata.

Именно комбинация этих двух слоёв делает возможной работу не минуты, а недели и месяцы.
