# Project Request

Заполните этот файл простыми словами.

## 1. Что вы хотите сделать

Опишите результат, который вам нужен.

## 2. Для кого это делается

Опишите пользователя, клиента или внутреннего заказчика.

## 3. Какую проблему это решает

Опишите, почему этот проект вообще нужен.

## 4. Что уже существует

Укажите:

- есть ли уже код;
- есть ли существующий продукт;
- есть ли документация;
- есть ли репозиторий;
- есть ли дизайн или спецификация.

## 5. Какие ограничения важны

Например:

- сроки;
- бюджет;
- технологии;
- безопасность;
- интеграции;
- платформы.

## 6. Что считается хорошим результатом

Опишите, по каким признакам вы поймёте, что задача решена хорошо.

## 7. Что пока неясно

Перечислите неопределённости, если они уже известны.
