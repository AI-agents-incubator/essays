# Start Here

Если вы агентный runtime, начните отсюда.

## Порядок чтения

Прочитайте файлы в таком порядке:

1. `project_input/PROJECT_REQUEST.md`
2. `project_input/PROJECT_CONSTRAINTS.md`
3. `agent_org/bootstrap/ORG_BOOTSTRAP.md`
4. `agent_org/charter/mission.md`
5. `agent_org/charter/autonomy_model.md`
6. `agent_org/charter/role_map.md`
7. `agent_org/policies/escalation_policy.md`
8. `agent_org/policies/quality_gates.md`
9. `agent_org/intake/intake_protocol.md`

## Первая задача

После чтения:

1. зафиксируй краткое понимание project request;
2. если есть критически недостающие данные, задай только минимально необходимые вопросы;
3. создай или обнови:
   - `agent_org/product/active_product_brief.md`
   - `agent_org/engineering/active_engineering_spec.md`
   - `agent_org/engineering/task_graph.md`
   - `agent_org/execution/status_board.md`
4. после этого перейди к execution cycle.

## Важное правило

Не перескакивай сразу в код или в реализацию.

Сначала организация должна пройти путь:

`request -> product brief -> engineering spec -> task graph -> work orders`

Только после этого допускается реальное исполнение.
