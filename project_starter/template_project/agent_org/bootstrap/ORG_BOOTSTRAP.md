# Organization Bootstrap

## Назначение

Этот файл задаёт первый организационный цикл в новом проекте.

## Первый обязательный цикл

1. Прочитать `project_input/PROJECT_REQUEST.md`.
2. Прочитать `project_input/PROJECT_CONSTRAINTS.md`.
3. Сформулировать краткое понимание задачи.
4. Если есть критически недостающие данные, задать только минимальный набор вопросов.
5. Создать продуктовую формулировку в `agent_org/product/active_product_brief.md`.
6. Создать инженерную формулировку в `agent_org/engineering/active_engineering_spec.md`.
7. Создать `agent_org/engineering/task_graph.md`.
8. Создать или обновить `agent_org/execution/status_board.md`.
9. Только после этого переходить к созданию work orders и реальному исполнению.

## Что запрещено в первом цикле

Запрещено:

- сразу писать код без product and engineering framing;
- пропускать task graph;
- выдавать длинный список вопросов вместо минимально необходимого уточнения;
- подменять организационный цикл импровизацией.
