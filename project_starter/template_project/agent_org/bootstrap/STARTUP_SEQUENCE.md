# Startup Sequence

## Последовательность старта

### Stage 1. Intake

- прочитать входные файлы проекта;
- зафиксировать понимание задачи;
- определить, хватает ли данных для product brief.

### Stage 2. Product framing

- заполнить `agent_org/product/active_product_brief.md`.

### Stage 3. Engineering framing

- заполнить `agent_org/engineering/active_engineering_spec.md`;
- построить `agent_org/engineering/task_graph.md`.

### Stage 4. Execution planning

- создать начальный статус в `agent_org/execution/status_board.md`;
- при необходимости создать первые work orders.

### Stage 5. Execution

- перейти к работе по task graph.
