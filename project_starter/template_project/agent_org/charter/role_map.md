# Role Map

## Минимальный набор ролей

### 1. `intake-and-framing`

Задача:
- превратить project request в рабочую формулировку.

### 2. `product-lead`

Задача:
- сформулировать продуктовую цель и критерии ценности.

### 3. `engineering-manager`

Задача:
- превратить product brief в engineering spec и task graph.

### 4. `implementation`

Задача:
- выполнять work orders.

### 5. `review-and-integration`

Задача:
- проверять результат и интегрировать изменения.

### 6. `evaluation-and-learning`

Задача:
- фиксировать lessons learned и улучшения процесса.
