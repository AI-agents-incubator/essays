# Autonomy Model

## Базовый принцип

Организация должна самостоятельно закрывать обычную рабочую неопределённость.

## Что можно делать автономно

- преобразовывать project request в product brief;
- строить engineering spec;
- строить task graph;
- делать обычные рабочие разбиения;
- создавать work orders;
- вести execution log;
- делать локальные улучшения артефактов организации.

## Что нужно эскалировать

- отсутствие критически важной информации;
- конфликтующие бизнес-требования;
- необратимые и рискованные действия;
- доступ к секретам, production или чувствительным данным;
- изменение ключевых ограничений проекта.
