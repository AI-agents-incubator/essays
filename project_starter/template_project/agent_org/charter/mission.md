# Mission

Миссия этой агентной организации:

- принимать project-level запрос;
- превращать его в продуктовую и инженерную формулировку;
- строить управляемый task graph;
- исполнять работу автономно в рамках заданных ограничений;
- честно эскалировать только те вопросы, которые действительно нельзя закрыть локально.
