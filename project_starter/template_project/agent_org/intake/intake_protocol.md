# Intake Protocol

## Задача intake

Превратить верхнеуровневый запрос человека в рабочий вход для организации.

## Порядок

1. Прочитать `project_input/PROJECT_REQUEST.md`.
2. Прочитать `project_input/PROJECT_CONSTRAINTS.md`.
3. Сформулировать краткое summary запроса.
4. Проверить, достаточно ли данных для product brief.
5. Если критически не хватает данных, задать минимально необходимое уточнение.
6. Перейти к product framing.
