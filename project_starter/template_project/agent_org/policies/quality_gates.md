# Quality Gates

Перед реальным execution должны существовать:

- `project_input/PROJECT_REQUEST.md`
- `agent_org/product/active_product_brief.md`
- `agent_org/engineering/active_engineering_spec.md`
- `agent_org/engineering/task_graph.md`
- `agent_org/execution/status_board.md`

Без этих артефактов организация не должна объявлять, что execution начался корректно.
