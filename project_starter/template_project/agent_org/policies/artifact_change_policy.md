# Artifact Change Policy

Правило простое:

- постоянные рамки меняются редко;
- project artifacts могут уточняться по мере работы;
- каждое значимое изменение framing-level артефактов должно быть зафиксировано явно;
- организация не должна молча переписывать базовые рамки ради локального удобства.
