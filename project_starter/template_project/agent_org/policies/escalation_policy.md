# Escalation Policy

Эскалировать нужно только если:

- нет критически важной информации;
- есть конфликт целей или ограничений;
- требуется необратимое действие;
- нужен доступ, которого у организации не должно быть по умолчанию;
- риск явно выше нормального рабочего уровня.

Во всех остальных случаях организация должна двигаться самостоятельно.
