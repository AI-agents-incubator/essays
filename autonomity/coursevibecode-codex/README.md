# Coursevibecode Codex Autonomy Pack

Это комплект шаблонов для настройки автономной работы Codex с проектом:
- `/Users/alexeykrolmini/Code/coursevibecode`

Эти файлы специально лежат вне проекта.
Они не применяются автоматически.
Их задача - дать тебе готовые инструкции и настройки, которые потом можно по шагам перенести в рабочий проект.

## Что входит в комплект

1. `01-user-config-template.toml`
   Шаблон пользовательского конфига Codex.
   Это то, что относится к общим настройкам в `~/.codex/config.toml`.

2. `02-project-config-template.toml`
   Шаблон project-level конфига.
   Это то, что потом можно положить в `.codex/config.toml` внутри `coursevibecode`.

3. `03-root-agents-template.md`
   Шаблон нового `AGENTS.md` для корня проекта.
   Он описывает именно курс, а не framework-adapter.

4. `04-codex-book-agents-template.md`
   Узкие инструкции только для ветки `2_lessons/codex-book`.
   Нужны, чтобы Codex писал книгу в правильном стиле и без лишних пауз.

5. `05-codex-book-backlog-template.md`
   Шаблон очереди работ для книги по Codex.
   Нужен для длинного автономного прохода по главам.

6. `06-apply-order.md`
   Порядок применения файлов.
   Это короткая инструкция: что переносить первым, что вторым и что проверять после каждого шага.

## Как использовать

Рабочая логика такая:
1. сначала обсудить и при необходимости подправить шаблон;
2. потом перенести его в реальный проект;
3. потом проверить, что Codex действительно увидел новую инструкцию или настройку;
4. только затем переходить к следующему слою.

## Важно

Текущие файлы проекта мы пока автоматически не заменяем.
Сначала согласуем содержимое, потом перенесем в `coursevibecode`.
