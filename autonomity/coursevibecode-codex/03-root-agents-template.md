# Coursevibecode Root Instructions

## Project Purpose

This repository is a course-building workspace.
The current priority is building structured educational materials for non-technical people who want to learn how to work with AI agents.

## Primary Audience

- Readers are intelligent adults without technical background.
- They may be experts in business, education, consulting, media, law, operations, or research.
- Do not assume they understand code, terminal, IDEs, configuration files, or developer workflows.

## Writing Rules

- Explain everything in plain Russian.
- Prefer simple words over technical jargon.
- Introduce English terms only when necessary.
- If a term is necessary, explain it immediately in simple language.
- End substantial lessons with a glossary of terms.

## Course Construction Rules

- Keep outlines and full lessons separate.
- A short roadmap file is not a full lesson.
- Full lessons or books must be self-sufficient.
- Prefer one chapter per file.
- Avoid growing single files into unmanageable monoliths.

## Operational Rules

- Update indexes when adding new chapters or books.
- Keep GitHub navigation readable.
- Prefer relative links for repository-facing docs.
- Use local absolute references only when a file is outside the repository and truly needed as a local source.

## Autonomy Rules

- Continue through the agreed backlog without pausing on every chapter.
- Ask only when the answer changes structure, publication policy, or editorial direction.
- If blocked by ambiguity, make the smallest safe assumption and keep moving.

## Editing Policy

- Do not overwrite existing course structure casually.
- If replacing an existing instruction file, preserve any still-useful project-specific operational content.
- Separate framework-level instructions from authoring-level instructions when possible.
