# 🚀 Проект: AI-Конвейер «Цифровое Бессмертие» (Vimeo → YouTube → RAG)

Этот проект превращает 3000+ часов видеоархива в структурированную базу знаний, доступную для ИИ-анализа.

## 🛠️ Стек инструментов
* **Язык:** Python 3.10+
* **Движок скачивания:** `yt-dlp` + `aria2c` (ускоритель).
* **Интеллект:** Gemini 1.5 Pro (через API и расширения).
* **Хранилище:** Локальный диск (для транзита) + YouTube (как индексер).
* **Формат базы:** Markdown (для RAG-систем).

---

## 📋 Пошаговый алгоритм запуска

### Шаг 1: Подготовка «Железа» (Local Setup)
Выполните эти команды в терминале вашего компьютера:
```bash
# Установка системных утилит
brew install yt-dlp ffmpeg aria2

# Установка библиотек Python
pip install pandas requests google-api-python-client google-auth-oauthlib google-generativeai
```

### Шаг 2: Получение ключей доступа (Критически важно)
Вам нужно подготовить два «паспорта» для скриптов:
1.  **Vimeo Token:** Создайте на [Vimeo Developer](https://developer.vimeo.com/apps). Нужны права `public`, `private`, `video_files`.
2.  **Google Credentials:** В [Google Cloud Console](https://console.cloud.google.com/) включите **YouTube Data API v3** и скачайте файл `client_secret.json`.

## 🏗️ Структура модулей конвейера

### Модуль №1: Инвентаризация (Inventory)
**Файл:** `1_vimeo_list.py`
**Действие:** Скрипт заходит в ваш Vimeo через API и выгружает CSV-файл со всеми 3000 ссылками и названиями.
* *Результат:* файл `vimeo_master_list.csv`.

### Модуль №2: Транзит (The Pipe)
**Файл:** `2_transit_engine.py`
**Действие:** Самый тяжелый этап. Работает по циклу:
1.  Берет ссылку из CSV.
2.  Скачивает видео в **240p** (через `yt-dlp -f worst`).
3.  Загружает его на ваш технический YouTube-канал (Private).
4.  Удаляет локальный файл.
* *Результат:* Ваш архив «переехал» в облако Google для анализа.

### Модуль №3: Смысловая индексация (Intelligence)
**Файл:** `3_knowledge_base.py`
**Действие:**
1.  Запрашивает у YouTube расшифровку (Transcript).
2.  Отправляет текст в Gemini.
3.  Создает Markdown-файл с суммаризацией и ключевыми тезисами.
* *Результат:* Папка `Knowledge_Base/` с тысячами файлов `.md`.

## 💡 Почему это сработает?
* **Минимальный трафик:** Мы не качаем терабайты. В 240p весь ваш архив весит меньше одного современного игрового диска.
* **Бесплатная транскрибация:** YouTube делает расшифровку бесплатно и профессионально.
* **Сквозной поиск:** Через неделю вы сможете спросить у бота: *«Что я говорил про советский менталитет в 2015 году на том длинном семинаре?»* — и он даст точную цитату.
