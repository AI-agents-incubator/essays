# Playwright

Эта папка зарезервирована под материалы по `Playwright`: браузерная автоматизация, extraction workflows, UI-тестирование и практики, где агенту нужно управлять реальным веб-интерфейсом.

Сейчас содержимого здесь нет. Когда раздел начнет заполняться, сюда логично складывать:

- заметки по browser automation;
- примеры скриптов и сценариев;
- кейсы extraction и form automation;
- материалы, связанные с веб-тестированием и обходом UI.

Если документ относится в первую очередь к общему курсу по code agents, ему лучше оставаться в [code-agents](/code-agents/README.md). В эту папку стоит класть уже более предметные материалы именно про `Playwright`.
