# Tools

Основной контентный раздел репозитория: учебные материалы, книги, playbooks и вспомогательные спецификации по инструментам для кода и агентных систем.

## Что здесь лежит

- `root_docs/` — guides, explainers, comparisons, learning paths и reference notes.
- `codex-book/` — полная книга по `Codex`.
- `claude-code-book/` — полная книга по `Claude Code`.
- `playbooks/` — прикладные пошаговые workflow.
- `reports/` — еженедельные tooling watchlist reports.
- `tooling_watchlist.md` — спецификация мониторинга инструментов для кода и агентных систем.
- `twitter_product_filter.md` — спецификация фильтрации продуктовых сигналов из X/Twitter.
