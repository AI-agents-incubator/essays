# Tooling Watchlist — Reports

Еженедельные отчёты по инструментам для кода и агентных систем.

## Кейсы: когда сюда идти

- Если вам нужно не учиться с нуля, а понять, что нового произошло на рынке code agents за последнюю неделю, смотрите отчеты в этой папке.
- Если вы хотите понять стартовый формат таких отчетов и увидеть первый широкий срез по рынку, откройте [tooling_watchlist_2026-03-22.md](tooling_watchlist_2026-03-22.md).
- Если вам нужен более зрелый weekly snapshot с акцентом на безопасность агентов, CLI-флаги и execution boundaries, смотрите [tooling_watchlist_2026-03-23.md](tooling_watchlist_2026-03-23.md).
- Если вы хотите не просто читать готовые отчеты, а воспроизводимо генерировать новые, используйте спецификацию [../tooling_watchlist.md](../tooling_watchlist.md).
- Если вас интересует более широкий фильтр внешних продуктовых сигналов из X/Twitter, а не только weekly report по ключевым tools, смотрите [../twitter_product_filter.md](../twitter_product_filter.md).
