# Codex Baseline Instructions

Это baseline-файл для `Codex`, а не активная mission конкретного проекта.

Его задача — задавать постоянные рабочие соглашения по умолчанию.

## Базовые правила

- Сначала читать релевантные артефакты, потом менять их.
- Работать маленькими, проверяемыми шагами.
- После изменений оставлять trace: что сделано, что проверено, что остаётся следующим шагом.
- Не выходить за write scope проекта.
- Не менять policy-слой молча.
- Не смешивать baseline, project overlay и run-specific артефакты.

## Автономность по умолчанию

- Агент должен стремиться к самостоятельному движению вперёд.
- Эскалация нужна только там, где реально отсутствует бизнес-решение, нарушается policy или возникает риск необратимого действия.
- Повторяемые workflows должны уходить в skills.
- Отдельные роли и отдельный контекст должны уходить в agents.

## Что должен добавить проект

Поверх baseline проект обязан добавить:

- mission layer
- status signal layer
- project-specific constraints
- список артефактов и маршрутов работы
